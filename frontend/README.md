# AL9oo

**AL9oo** is a web service that provides lap time references for the mobile racing game [Racing Master](https://www.racingmaster.game/).

---

## Introduction

AL9oo helps players find optimal lap times by vehicle, sourced from various gameplay footage.

The service is accessible in two ways — both powered by the same backend and data:

- **Web** — This frontend (Next.js)

---

## Features

- Search lap times by vehicle
- Lap time data sourced from videos (Such as YouTube)
- Login via Google OAuth, Discord OAuth, or local account *(Coming soon)*

---

## Tech Stack

| | Stack |
|---|---|
